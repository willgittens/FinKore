FinKore project overview

FinKore documentation

FinKore defines portable financial behavior for Money, Workflow, Audit, Approvals, and Financial Entities. FinKore Core 2.0.1 is stable within the scope defined by the specification.

The repository publishes specifications, acceptance artifacts, and maintenance tools. Consumers own financial implementations and execution.

Read the contract

  • CoreDoc — foundation-level financial obligations.
  • Specification — normative behavior and domain boundaries.
  • Conventions — compatibility, stable identifiers, portable values, and errors.
  • Glossary — shared domain terminology.

Implement and evaluate

  • Implementation guide — build consumer-owned implementations from the specification.
  • Conformance artifacts — manifest, schemas, and portable acceptance cases.
  • Consumer guide — discovery, evaluation, reporting, and conformance claims.
  • Fixture operation contracts — inputs, observations, and failure interpretation.
  • Requirement traceability — published coverage and its limitations.
  • Agentic Contract — canonical operation semantics and safety metadata.

Contribute and verify

  • Contributing — coordinated changes and compatibility review.
  • Developer tools — local artifact verification and supported Node setup.
  • Release notes — concise release history.

Repository checks validate published artifacts. They do not execute financial operations or establish that an external implementation conforms.
