Getting Started

Start with the specification

The Knowledge Base collects explanations, examples, and decision notes to help people and agents understand FinKore without turning supporting documentation into a second specification.

The recommended flow starts with normative behavior, moves through conformance vectors, and only then reaches implementations. That keeps each example traceable to what the project actually defines.

Overview

FinKore is specification-first: the specification defines financial behavior, while conformance, the Agentic Contract, and implementations follow that contract.

Architecture

  • Specification

    The canonical source for requirements, invariants, and financial semantics.

  • Conformance

    Language-independent vectors derived from the specification.

  • Agentic Contract

    Canonical operations, portable errors, effects, and traceability.

  • Implementations

    Idiomatic language APIs that preserve the defined behavior.
