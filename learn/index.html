One rule in practiceRounding

Which rounding rule applies?

10.005EUR
→
10.00EUR
↳

HALF_EVEN. Scale 2. An explicit result.

The original 10.005 EUR stays unchanged.

At a tie, HALF_EVEN selects the nearest value whose last retained digit is even.

See the rule and acceptance case
Rule: MONEY-ROUNDING-003 Case: money.round.half-even.tie-even-down-001

Expected result: 10.00 EUR, with the original operand unchanged.

How it works

The rules are shared.
The implementation is yours.

Rounding an amount, rejecting a transition, preserving a decision: small details carry financial meaning. FinKore documents them before they become assumptions in your code.

The repository provides specifications and acceptance artifacts. Your team owns the code, business policy, and execution of the cases.
