# FinFlow TypeScript Conformance Adapter

Adapter from FinFlow conformance operation IDs to the TypeScript reference implementation.

This milestone supports only:

- `finflow.money.add`
- `finflow.money.subtract`
- `money.deserialize`
- `money.serialize`

It does not claim support for Money comparison, rounding, multiplication, division, workflow, audit, approvals, entities, MCP, or executable agent integrations.
