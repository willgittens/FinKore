# Draft 0.7 Release Evidence

Draft 0.7 does not add a closed Core conformance profile, capability
declaration, claim record, portable error, or canonical operation ID.

This directory records release-candidate checksum evidence for the
non-normative Draft 0.7 composition reference scope. The checksum manifest is
validated by:

```bash
npm run checksums:check:draft0.7
```

The manifest is release evidence only. It does not make the Draft 0.7 reference
application profiles part of the normative conformance manifest.
